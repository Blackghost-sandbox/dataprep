# DataPrep

Premium desktop learning workspace for data engineering interview preparation, built with Next.js 15, React, TypeScript, Tailwind CSS, shadcn/ui, Lucide, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Included interactions

- Animated sidebar collapse and expanded Spark curriculum
- Interactive lesson tabs
- Animated progress indicators
- PySpark, Scala, and SQL code switching
- Copy-to-clipboard feedback
- Card hover elevation
